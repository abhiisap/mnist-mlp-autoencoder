# Neural Network and Representation Learning on MNIST

This project implements a neural network classifier and autoencoder to analyze handwritten digit data (MNIST).

## Features
- MLP classifier for digit recognition
- Autoencoder for latent representation learning
- Cosine similarity analysis of learned embeddings
- Visualization using confusion matrix and heatmaps

## Project Structure
src/       → model code  
data/      → dataset  
outputs/   → results  

## Tech Stack
Python, NumPy, Scikit-learn, Matplotlib, Seaborn

## How to Run
pip install -r requirements.txt  
python src/mlp_classifier.py  
python src/autoencoder.py
